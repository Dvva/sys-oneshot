# 屏蔽迅雷「开通超级会员」弹窗 —— 完整思路与脚本

> 时间：2026-11-08
> 环境：Windows 10 22H2 (19045)、迅雷 12.4.9.3916 / 25.0.82.1560、安装于 `D:\迅雷12\Thunder`
> 目标：复制链接 → 下载框点确定后，不再弹出「开通超级会员解锁更多权益」付费页（288 元 / 二维码）
> 约束：保留「复制链接自动弹下载框」的功能，只去掉会员推广

本文给其他 AI 复用：包含**怎么定位**、**为什么常规办法无效**、**可运行脚本**。

---

## 一、结论先行

| 层 | 手段 | 作用 | 是否持久 |
|---|---|---|---|
| 1 | 改名禁用 `VipPayCenter2025` 插件 | **这条最关键**，直接消除 288 元会员弹窗 | 持久（实测 19 小时未被恢复） |
| 2 | hosts 屏蔽 8 个活动域名 | 挡住「玩游戏领会员」这类活动页 | 持久，但可能被系统/其他软件重置 |
| 3 | `Profiles\config.json` 关两个开关 | 去掉引导气泡、VIP 团队入口 | 持久（本地配置） |

**只做 hosts 是没用的**——这是最容易踩的坑，见第三节。

## 二、诊断过程（关键路径）

### 2.1 先确认弹的是什么

弹窗标题「开通超级会员解锁更多权益」，尺寸约 860×580，带会员权益对比表和支付二维码。

### 2.2 第一直觉：抓域名

```powershell
# 从迅雷内置浏览器历史里找 URL
Get-Content 'D:\迅雷12\Thunder\Profiles\BrowserHistorySites.json'
Get-Content 'D:\迅雷12\Thunder\Profiles\historys.json'
```

找到的是 `https://act-youxi.xunlei.com/play-get-vip-v2?...`（标题「玩游戏领会员」），
**但那不是后来弹的那个 288 元页**。

### 2.3 判断「URL 是本地还是远程」

关键一步——在迅雷整个安装目录里搜这个 URL：

```python
import re
from pathlib import Path
root = Path(r'D:\迅雷12\Thunder')
pat = re.compile(rb'https?://[a-zA-Z0-9./_?=&%\-]*(?:vip|paycenter)[a-zA-Z0-9./_?=&%\-]*xunlei\.com[a-zA-Z0-9./_?=&%\-]*')
for p in root.rglob('*'):
    if not p.is_file() or p.suffix.lower() not in ('.exe','.dll','.json','.js','.html','.htm'): continue
    if p.stat().st_size > 60*1024*1024: continue
    data = p.read_bytes()
    for m in pat.finditer(data):
        print(p, m.group(0).decode('utf8','ignore')[:120])
```

结果：URL **只出现在 `Profiles\BrowserHistorySites.json` 和 `historys.json`**（都是历史记录本身）。

**推论**：这个 URL 不在程序里 → 是服务器下发的 → 屏蔽域名有效。
但历史里没有 288 元页的 URL → 说明**它根本不是网页**。

### 2.4 换思路：搜本地页面

按弹窗上的中文关键词搜整个安装目录：

```python
from pathlib import Path
root = Path(r'D:\迅雷12\Thunder')
needles = ['超级会员'.encode('utf-8'), '超级会员'.encode('gbk'), '解锁更多权益'.encode('utf-8')]
for p in root.rglob('*'):
    if not p.is_file() or p.suffix.lower() not in ('.html','.htm','.js','.json','.css','.asar','.txt'): continue
    data = p.read_bytes()
    for n in needles:
        if n in data:
            print(p.relative_to(root)); break
```

命中两个：

```
Profiles\PersonalInfo\vip-config.json
program\resources\app\plugins\VipPayCenter2025\2.0.7.asar
```

**找到了**。

### 2.5 确认就是它

```powershell
Get-Content 'D:\迅雷12\Thunder\program\resources\app\plugins\VipPayCenter2025\config.json'
```

```json
{
  "name": "vip-pay-center",
  "version": "2.0.7",
  "main": "2.0.7.asar/index.js",
  "owner": "vip-plugin-controller",
  "dialogWidth": 860,
  "dialogHeight": 580,
  "isShowLoginDialog": false
}
```

`dialogWidth: 860, dialogHeight: 580` 与截图弹窗尺寸完全一致 —— 确认无疑是它。

## 三、为什么只屏蔽域名没用

迅雷 12 是 **Electron + CEF 混合架构**：

- `program\resources\app\plugins\` 下是本地 Electron 插件，`main` 指向 `*.asar` 里的 `index.js`
- 这些插件**从本地磁盘加载 UI**，不经过网络
- hosts / DNS / 防火墙对它完全无效

所以必须**让插件加载不到**，而不是拦它的网络请求。

## 四、三层方案细节

### 第 1 层：禁用会员付费插件（核心）

```powershell
# 1. 必须彻底退出迅雷，否则目录被占用改不了名
Get-Process thunder,ThunderStart,xllite,ThunderCmd | Stop-Process -Force
Start-Sleep -Seconds 5

# 2. 备份到 plugins 之外（避免被当插件扫描）
New-Item -ItemType Directory -Force -Path 'D:\迅雷12\Thunder\_plugin_backup' | Out-Null
Copy-Item 'D:\迅雷12\Thunder\program\resources\app\plugins\VipPayCenter2025' `
          'D:\迅雷12\Thunder\_plugin_backup\VipPayCenter2025' -Recurse -Force

# 3. 改名禁用
Rename-Item 'D:\迅雷12\Thunder\program\resources\app\plugins\VipPayCenter2025' 'VipPayCenter2025.off'
```

注意：

- **只 `taskkill` 一次不够**，迅雷有 9~12 个进程（thunder、ThunderStart、xllite、ThunderCmd…），要按名字全杀
- 直接改名如果不成功，报 `Access to the path ... is denied`，就是还有进程占用
- 备份目录**必须移出 `plugins\`**，否则 `*.disabled` 之类可能仍被扫描

**实测**：禁用后 19 小时未被迅雷自动恢复，`config.json` 里的 `"clear": true` 并没有触发重装。

### 第 2 层：hosts 屏蔽活动域名

```powershell
$domains = @(
  'act-youxi.xunlei.com','act-vip-ssl.xunlei.com','dy1-vip-ssl.xunlei.com',
  'dyactive2-vip-ssl.xunlei.com','faileddy1-vip-ssl.xunlei.com',
  'video-vip-ssl.xunlei.com','control-vip.xunlei.com','dy1-report-vip.xunlei.com'
)
$hosts = "$env:SystemRoot\System32\drivers\etc\hosts"
Copy-Item $hosts "$hosts.bak_$(Get-Date -Format yyyyMMdd)" -Force
$lines = @('','# ==== Thunder ad domains ====')
foreach ($d in $domains) { $lines += "0.0.0.0 $d" }
$lines += '# ==== end Thunder ad domains ===='
Add-Content $hosts $lines -Encoding ascii
ipconfig /flushdns
```

**只屏蔽这些，不要碰**：`api-pan`、`download`、`client`、`api-shoulei`（下载与解析）、
`xluser-ssl`（登录）、`upgrade-pc-ssl`（升级）、`vip.xunlei.com`（会员中心本身）。

判断方法：扫出全部 72 个 `*.xunlei.com` 域名后，只挑「名字里带 `act-` / `dy1-vip` / `control-vip` / `video-vip`」的。

### 第 3 层：本地配置

`D:\迅雷12\Thunder\Profiles\config.json`：

```json
"GUIDE_INFO": { "isShowBubble": false },
"VipDownload": { "TeamEnteranceSwitch": false }
```

保留 `"Monitor": { "WatchTraditionLink": true }` —— 这才有「复制链接弹下载框」。

> `global_remote_config.json` 里的 `Promote.OpenFilePromoteSwitch`（推广 360压缩/2345看图/WPS）
> 是**服务器下发的缓存**，改了会在下次同步被覆盖，不要指望它。

## 五、可运行脚本

脚本：同目录 `block_thunder_popup.ps1`

```powershell
# 预演，什么都不改
.\block_thunder_popup.ps1 -WhatIfOnly

# 执行屏蔽（右键「以管理员身份运行」，会先退出再启动迅雷）
.\block_thunder_popup.ps1

# 还原
.\block_thunder_popup.ps1 -Restore
```

脚本做的事：

1. 从注册表/常见路径定位迅雷安装目录
2. 备份 hosts、config.json、插件目录
3. hosts 追加 8 条 `0.0.0.0`
4. 插件改名 `VipPayCenter2025` → `VipPayCenter2025.off`
5. config.json 关 `isShowBubble` / `TeamEnteranceSwitch`
6. 刷新 DNS、重启迅雷

**坑**：写回 `config.json` 必须**无 BOM**。PowerShell 5.1 的 `Set-Content -Encoding UTF8` 会加 BOM，
迅雷可能读不了；脚本里用 `[IO.File]::WriteAllText($cfg,$text,[Text.UTF8Encoding]::new($false))`。

## 六、验证方法

```powershell
# 1) 域名应解析失败或指向 0.0.0.0
[System.Net.Dns]::GetHostAddresses('act-youxi.xunlei.com')   # 应抛异常
Test-NetConnection act-youxi.xunlei.com -Port 443 -InformationLevel Quiet  # 应为 False

# 2) 核心功能域名必须正常
Test-NetConnection download.xunlei.com -Port 443 -InformationLevel Quiet    # 应为 True

# 3) 插件状态
Get-ChildItem 'D:\迅雷12\Thunder\program\resources\app\plugins' -Directory   # 应只有 VipPayCenter2025.off

# 4) 配置
(Get-Content 'D:\迅雷12\Thunder\Profiles\config.json' -Raw | ConvertFrom-Json).GUIDE_INFO.isShowBubble  # 应 False
```

最终验证靠实际操作：复制一个链接 → 下载框应正常弹出 → 点确定 → 不应再出现 288 元会员页。

| 影响 | 说明 |
|---|---|
| 「开通会员」按钮点了没反应 | 插件被禁用，属预期 |
| 会员中心页面 | 不受影响（`vip.xunlei.com` 没屏蔽） |

## 八、排查下一个弹窗的通用套路

如果以后又出现新弹窗，按这个顺序查：

1. **先截图看标题和尺寸** —— 中文标题是搜索关键词
2. **查内置浏览器历史**（`BrowserHistorySites.json` / `historys.json`）—— 有 URL 就是网页
3. **在整个安装目录搜这个 URL**
   - 搜不到 → 服务器下发 → 走 hosts 屏蔽
   - 搜得到 → 本地资源 → 走插件/文件禁用
4. **搜不到 URL 就搜页面上的中文关键词**（"超级会员"、"解锁更多权益"）—— 能定位到 `.asar`
5. **看 `config.json` 里的 `dialogWidth/dialogHeight`** —— 和截图尺寸对上就是它
6. **禁用插件时**：杀全部迅雷进程 → 备份移出 `plugins\` → 改名
