关闭 Edge 下载安全警告
========================================

【这是什么】
一次性补丁：跑一次永久生效，随时可卸载。
属于「系统策略类」补丁，改的是注册表 HKLM 下的 Edge 企业策略。

【解决什么问题】
从网上下载 exe / reg / bat / msi 等文件时，Edge 会拦一道
「不常下载，可能有危险」的提示，每次都要点「保留」。
这个补丁把常见 18 种扩展名加进 Edge 的豁免列表。

【怎么用】
  应用：双击「应用.cmd」（或右键以管理员身份运行 .\应用.ps1）
  卸载：双击「卸载.cmd」——会先把整棵策略键导出到 _备份\<时间戳>\ 再删除

【文件说明】
  应用.ps1       应用 / 检测 / 卸载 全部逻辑
  卸载.ps1       卸载入口（等价于 应用.ps1 -Restore）
  应用.cmd       双击入口（自动请求管理员）
  卸载.cmd       双击入口（自动请求管理员）
  原版注册表.reg 最初来源的 .reg 原档，**脚本不依赖它**，仅作留档

【改了哪里】
  HKLM\SOFTWARE\Policies\Microsoft\Edge\ExemptFileTypeDownloadWarnings
  下面 18 个字符串值（1~18，缺 5，与原版一致）：
    exe reg bat vbs msi js inf cmd dll sys url ocx apk crx xml msc mht
  每个值形如：
    {"file_extension": "exe", "domains": ["*"]}

【副作用】
  Edge 设置页会出现「由你的组织管理」字样，这是企业策略的正常提示，不是被入侵。
  卸载后该提示消失。

【想恢复原状】
  双击「卸载.cmd」。备份在 _备份\<时间戳>\，双击里面的 .reg 也能单独还原。
